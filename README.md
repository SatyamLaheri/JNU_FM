# JNU Bus

A nostalgic Hindi music player inspired by the JNU campus bus journey.

## About

JNU Bus is a browser-based music experience designed around the feeling of riding the campus bus through Jawaharlal Nehru University — twilight over red-brick buildings, familiar songs in your headphones, and the long ride home at night.

Instead of being another music player with a playlist, JNU Bus turns listening into a small visual journey — combining a cinematic JNU campus environment, atmospheric rain, and a glassmorphic music player into a single cohesive experience.

## Features

- Nostalgic Hindi & retro Bollywood playlist (77+ tracks)
- JNU campus background artwork
- Glassmorphic music player with rain effects
- Bus ticket sharing
- Keyboard shortcuts
- Mobile-friendly responsive design

## Getting Started

```bash
npm install
npm run dev
```

## Tech Stack

- React 19 + TanStack Start + Vite
- Tailwind CSS 4
- shadcn/ui components
